GitHub 学生包：一次认证，白拿 80 多个开发者福利

GitHub Student Developer Pack 是 GitHub 给学生的免费大礼包：验证一次学生身份，就能领 GitHub 自己和约 80 个合作伙伴的免费福利，包括 Copilot、GitHub Pro、云服务器额度、开发工具和免费域名。不用花一分钱，在读期间一直有效。

先说清楚两件事：第一，包里的合作福利经常变，本文列的是 2026 年 10 月核对过的项目，领的时候以官网 pack 页显示的为准；第二，Copilot 学生版 2026 年 3 月改版后，新开通一度暂停过，申请时能不能开以官网显示为准，别的地方说"包领"都别信。

申请条件

  • 年满 13 岁，有个人 GitHub 账号（组织账号不行）
  • 正在学位或文凭课程在读：高中、大学、研究生、在家上学都算
  • 能证明在读身份：学校邮箱最快；没有学校邮箱就上传学生证、在读证明或成绩单照片
  • Azure 那 $100 额度要年满 18 岁才能领

第 1 步：准备一个个人 GitHub 账号

没有就去 github.com 注册一个，用户名想好，之后领福利、写代码都用它。资料填真实姓名和学校，和证件对得上，审核才快。

第 2 步：打开学生包页面申请

打开 https://education.github.com/pack，点 Sign up for Student Developer Pack（也可以从 GitHub 设置里的 Education 入口进）。按提示选你的学校、填入学信息。

第 3 步：验证学生身份

有学校邮箱最快：填学校邮箱，收验证邮件点确认，一般很快通过。

没有学校邮箱：上传在读证明，学生证正反面照片、在读证明或带学校抬头的成绩单都行，拍清楚，别传裁切过的截图。审核一般几天内出结果，多数在 72 小时左右。

注意：姓名、学校、入学时间要和证件完全一致，拼写差一个字母都可能被打回重交。被拒了按提示补材料再交一次就行，不用重新注册。

第 4 步：通过后逐个领取

通过后回到 pack 页面，福利列表里每个项目点进去按提示领。建议先领这几个：GitHub Pro、Copilot Student、Codespaces、Azure $100、JetBrains、免费域名。其他的用得着再领，反正一直在那。

常见问题

高中生能申吗？
能。13 岁以上、在学位或文凭课程在读就行，高中也算。只是 Azure 的 $100 额度要满 18 岁。

没有学校邮箱怎么办？
上传学生证或在读证明走人工审核，一样能过，就是慢一点。

Copilot 到底能不能领？
2026 年 3 月学生版改版后，新开通一度暂停。能不能开以你申请时官网显示为准，领不到就先用 Copilot Free 顶着，其他福利不受影响。

毕业了福利还在吗？
不在。毕业、失去学生身份后福利陆续失效，JetBrains 这类按年续的也续不了。

和谷歌学生认证冲突吗？
不冲突。一个是 GitHub 的开发者福利，一个是 Google 的 AI 套餐，两个都能领。谷歌那个 2026 年 12 月 31 日截止，见本站教程：谷歌学生认证：免费领一年 Google AI Pro / AI Plus。
