免费搭建 Cloudflare 节点：10 分钟部署 VLESS 节点

用 Cloudflare Pages + 开源项目 edgetunnel，免费搭一个自己的 VLESS 节点。成本 0 元，不用信用卡，日常上网够用。

先说清楚：这不是永久稳定的商业节点。出口是 Cloudflare 的共享机房 IP，AI 和流媒体容易风控，免费版每天 10 万次请求，超了当天就用不了。只适合自己用，别分享给别人。

准备工作

  • 一个 Cloudflare 账号（免费版就行）
  • 一个免费域名（本文用 DNSHE 注册的免费域名，托管到 Cloudflare）
  • 一部手机 / 电脑，装好 Quantumult X 或 Shadowrocket

第 1 步：注册免费域名，托管到 Cloudflare

去 DNSHE 注册一个免费域名，拿到域名后，在 Cloudflare 添加站点，按提示把域名的 NS 改成 Cloudflare 给你的那两个，等状态变成 Active。

第 2 步：创建 KV 命名空间

在 Cloudflare 后台，Workers KV 里新建一个命名空间，名字随便起，比如 cs334-kv，位置选标准。

第 3 步：下载 edgetunnel 源码

打开 GitHub 上的 cmliu/edgetunnel 仓库，下载 main.zip。只用 GitHub 官方源码，别下任何博客提供的安装包。

下载地址：https://github.com/cmliu/edgetunnel/archive/refs/heads/main.zip

第 4 步：新建 Pages 项目，上传 main.zip

Cloudflare 后台 → Workers 和 Pages → 创建应用程序 → Pages → 上传资产（拖放文件）。

项目名起个中性的，比如 cs334-site，不要带 edgetunnel、vless、trojan 这些词，容易被标记。上传 main.zip，点部署站点。

注意：不要用 Worker + Git 部署的老办法，也不要复用之前报过 1101 的项目名，换新名字、走 Pages 上传才稳。

第 5 步：设置 ADMIN 密码

进新项目 → 设置 → 变量和密钥 → 添加变量：环境选生产，变量名 ADMIN，值填你自己定的管理密码，密钥勾上，保存。

然后回部署页，创建部署，重新上传一次 main.zip，让 ADMIN 生效。

第 6 步：绑定 KV

设置 → 绑定 → 添加绑定 → KV 命名空间，变量名填 KV，选第 2 步建的那个命名空间，保存。

再去部署页，创建部署，重新上传一次 main.zip，让 KV 生效。

第 7 步：打开管理页，拿到订阅

打开 https://你的项目名.pages.dev/admin，用 ADMIN 密码登录，就能看到节点链接和订阅链接。

订阅链接长这样：https://你的项目名.pages.dev/sub?token=xxxx

第 8 步：导入客户端

Shadowrocket：点右上角 +，类型选 Subscribe，粘贴订阅链接，保存，选节点，开启。

Quantumult X：订阅链接是一份完整配置文件，不能当节点资源导。去设置 → 配置 → 下载配置，粘贴订阅链接后面加上 &target=quanx，下载并应用，节点就进来了。如果一开就报 MitM 证书错误，先把重写规则关掉再开。

第 9 步：测一下 IP 干不干净

开节点后，浏览器打开 ip.sb 看出口 IP 和位置，再打开 ping0.cc 看风控值、是不是原生 IP、AI 应用合不合适。风控值越低越好，20% 左右算干净。

日常使用建议

  • 分流开着，国内网站走直连，国外网站走节点，最省额度。
  • 刷网页、聊天、看短视频、偶尔用 AI，都够用。
  • 别 24 小时挂着看高清视频、下载大文件，也别分享订阅链接给别人。
  • 免费版按每天 10 万次请求算，大概相当于每天 5-10GB 的普通上网量，超了等第二天恢复，不会扣钱（没绑信用卡）。
  • 想稳用 AI、做 TikTok、电商运营，Cloudflare 机房 IP 不够干净，得换住宅 IP 的出口，那是另一回事。
