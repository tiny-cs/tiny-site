JetBrains 学生包：全套 IDE 免费一年，在读可续

JetBrains 学生包是给在读学生的免费授权：验证一次学生身份，就能免费使用 JetBrains 全套专业 IDE，包括 IntelliJ IDEA Ultimate、PyCharm 专业版、WebStorm、GoLand、CLion 等 10 个 IDE，外加 JetBrains Academy 的动手编程课。在读期间每年续期，不用花钱。

先说清楚两件事：第一，学生包给的是 IDE 本身，不包括 JetBrains AI Pro 付费订阅，学生只能用 AI 免费档，外加一次 30 天 AI Pro 试用；第二，申请要求是全日制在读、课程至少一年，短期网课、训练营、Bootcamp 不符合条件。

一个授权可以在多台设备上用，个人电脑和笔记本都能装。只能用于非商业的教育用途，包括课程作业和学术研究，不能拿去做商业项目赚钱。

申请条件

  • 在正规学校全日制在读：高中、大学、研究生都算，课程要一年以上
  • 能证明学生身份，三种方式任选一种：学校邮箱、ISIC / ITIC 国际学生证、GitHub 学生包账号
  • 学校邮箱是最快的；学校邮箱不在 JetBrains 认可列表里时，改用 GitHub 学生包或 ISIC 验证
  • 短期在线课程、Bootcamp、训练营不符合条件，申请会被拒

第 1 步：准备验证材料

三选一，提前备好：学校邮箱（能收验证邮件的）、ISIC / ITIC 卡号，或者已经通过的 GitHub 学生包账号。没有 GitHub 学生包的可以先看本站教程：GitHub 学生包：一次认证，白拿 80 多个开发者福利，拿下 GitHub 学生包之后，再用它来验证 JetBrains 也行。

第 2 步：打开学生包页面申请

打开 https://www.jetbrains.com/academy/student-pack/，点 Apply for Student Pack / Request now，按提示填学校、姓名和验证方式。用学校邮箱就填邮箱收验证邮件；用 GitHub 学生包或 ISIC 就按页面提示关联账号。

第 3 步：等审核，登录账号下载

学校邮箱验证一般很快，人工审核要等几天。通过后登录你的 JetBrains 账号，去官网下载要用的 IDE，登录同一个账号就能激活，不用再输激活码。

注意：姓名、学校、入学时间要和证件完全一致。被拒了按提示换一种验证方式再交一次就行，不用重新注册账号。

第 4 步：每年续期

授权有效期一年，到期前两周 JetBrains 会发邮件提醒，在 JetBrains 账号里点续期链接重新验证一次就行。只要还在读，每年都能续；毕业后就续不了了，但毕业优惠还在，2 年内买产品打 6 折。

常见问题

AI Pro 免费吗？
不免费。学生包只含 IDE，不含 AI Pro 付费订阅。学生能用的是 AI 免费档，外加一次 30 天 AI Pro 试用。

没有学校邮箱怎么办？
用 GitHub 学生包账号或 ISIC / ITIC 卡验证，一样能过。学校邮箱域名不在认可列表里时也一样，换这两种方式。

Bootcamp / 网课学生能申吗？
不能。只认一年以上的全日制课程，短期课程、训练营、Bootcamp 都不符合。

能装几台电脑？
能装多台。像普通个人订阅一样，一个学生授权可以在多台设备上用。

能用来做商业项目吗？
不能。学生授权只限非商业的教育用途，包括课程和学术研究。

和 GitHub 学生包冲突吗？
不冲突。GitHub 学生包本身就包含 JetBrains 授权，而且还能反过来当 JetBrains 的验证材料，两个都领最划算。
