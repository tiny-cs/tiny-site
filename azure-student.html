Azure 学生版：$100 额度 12 个月，不用信用卡

Azure 学生版是微软给全日制大学生的免费云福利：12 个月内 $100 额度，注册时不用绑信用卡，还能用 25 个以上免费服务。拿来跑个小网站、部署课程项目、练机器学习都够用，在读期间每年可以续一次。

先说清楚三件事：第一，额度 12 个月到期或用完，订阅就会停掉，不会自动扣你的钱；第二，领的时候不用信用卡，但必须是年满 18 岁的全日制大学生；第三，额度用完之前记得关掉不用的服务，空跑的虚拟机最烧额度。

能拿到什么

内容说明
$100 额度12 个月内用在大部分 Azure 产品上，用不完不顺延
25 个以上免费服务虚拟机、存储、数据库、App Service 等常驻免费额度
信用卡注册时不需要绑卡
有效期12 个月，在读期间每年续一次

常见的用法：一台小虚拟机 24 小时跑着放个人网站或课程作品，够撑 12 个月；或者用 App Service 部署一个 Web 应用，配一个免费数据库。额度是按用量扣的，建服务之前先看一眼定价，别一上来就开大规格的机器。

申请条件

  • 年满 18 岁，在正规的两年制或四年制大学全日制在读
  • 用学校邮箱验证学生身份，验证由微软的合作方 SheerID 处理
  • 一个 Microsoft 账号只能领一次学生版订阅

第 1 步：打开 Azure 学生版页面

打开 https://azure.microsoft.com/free/students，用你的 Microsoft 账号登录（没有就先注册一个，Outlook 或 Hotmail 账号都能用）。点申请，按提示填姓名、国家、学校和出生日期，学校邮箱填你学校的邮箱。

第 2 步：验证学生身份

学校邮箱在微软名单里的，收一封验证邮件点确认就通过了，一般几分钟就能好。如果学校邮箱不在名单里，还有两条路：上传在读证明、学生证等官方文件走 SheerID 人工验证，一般 48 小时内出结果；或者先领 GitHub 学生包，用学生包的身份直接激活 Azure 学生版，不用再重复交材料。本站教程：GitHub 学生包：一次认证，白拿 80 多个开发者福利。

如果上面两条路都走不通，还有个 Azure 学生入门版（Azure for Students Starter）：不用验证、不用信用卡，能用 App Service、Functions、SQL 数据库等有限的免费服务，只是没有 $100 额度，适合先练手。

第 3 步：去 Azure 门户看额度

验证通过后打开 https://portal.azure.com，在订阅或教育中心里能看到学生版订阅和 $100 额度、到期时间。先建一个资源组，把练手的服务都放进同一个组里，不用了整个组删掉最干净，不会漏下还在扣费的服务。

到期和续期

额度 12 个月到期或用完，订阅会被停用，服务也会停掉，不会自动转付费扣钱。还在读的话每年重新验证一次就能续。想继续用的话，停用后 90 天内可以联系 Azure 支持升级成按量付费，但升级后就是正常计费了，升级前先确认价格。

常见问题

没有学校邮箱怎么办？
可以上传在读证明或学生证走 SheerID 人工验证，或者先领 GitHub 学生包再激活。实在都没有的，用学生入门版先练手。

额度能用来做什么？
大部分 Azure 产品都能用：虚拟机、网站托管、数据库、存储、AI 服务等。先看每个服务的免费额度和定价再开。

毕业了还能续吗？
不能。毕业后就续不了了，到期前把重要的数据和代码导出来，网站迁到别的免费托管上。

和 GitHub 学生包冲突吗？
不冲突。学生包里也包含 Azure 额度，两个渠道领的是同一类学生版，不用重复领，先领学生包再激活 Azure 最省事。
